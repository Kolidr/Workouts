# Local Panel

Статическое приложение с локальным хранилищем и переносом данных через файл.

## Запуск

Откройте index.html в современном браузере или разместите содержимое каталога
на статическом хостинге. Для первого запуска загрузите личный пакет.

## Перенос данных

В разделе «Данные» можно выгрузить резервную копию и загрузить её на другом
устройстве. Копия включает локальные материалы и записи.
